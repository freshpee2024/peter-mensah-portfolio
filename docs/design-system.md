# Design System

## Project Overview

This document defines the design principles, visual rules, and reusable components used throughout the portfolio website.

The goal is to maintain consistency, simplicity, and a professional user experience.

---

# Design Principles

## 1. Simplicity

The design focuses on clear layouts, readable content, and removing unnecessary visual distractions.

Every section should communicate its purpose quickly.

---

## 2. Clarity

Users should easily understand:

* Who I am
* What I build
* My skills
* My process
* How to contact me

---

## 3. Consistency

Reusable styles and components are used across the website to create a unified experience.

Examples:

* Buttons
* Cards
* Typography
* Spacing
* Animations

---

# Typography

## Primary Font

Poppins

Used for:

* Headings
* Navigation
* Body text
* Buttons

The font was selected because it provides:

* Modern appearance
* Good readability
* Clean professional feeling

---

# Color System

The portfolio uses a clean and modern color palette.

## Primary Color

Used for:

* Buttons
* Highlights
* Interactive elements
* Accent details

---

## Text Colors

Used for:

* Main headings
* Paragraph content
* Supporting information

The contrast is designed to maintain readability.

---

## Background Colors

Used to create:

* Visual separation between sections
* Clean page structure
* Comfortable reading experience

---

# Layout System

## Container

The website uses a centered container system to maintain:

* Balanced spacing
* Professional alignment
* Better readability on large screens

---

## Spacing Rules

Spacing follows a consistent scale using relative units such as:

* rem
* percentages
* flexible layouts

Common spacing examples:

* Small spacing: 0.5rem - 1rem
* Medium spacing: 1.5rem - 2rem
* Large spacing: 3rem+

---

# Component System

## Buttons

Buttons are designed with:

* Rounded corners
* Clear hover states
* Smooth transitions
* Interactive feedback

Features:

* Hover movement
* Shadow effects
* Shine animation
* Click feedback

---

## Cards

Cards are reusable content containers.

Used for:

* Skills
* Projects
* About section
* Contact information

Card features:

* Rounded corners
* Internal spacing
* Hover movement
* Light interaction effects

---

# Animation Guidelines

Animations should improve the user experience without becoming distracting.

Implemented animations:

## Scroll Animations

Used to reveal sections smoothly as users move through the page.

---

## Counter Animations

Used to create engaging statistics and highlight progress.

---

## Hover Animations

Used to provide feedback when users interact with:

* Buttons
* Cards
* Navigation links

---

# Responsive Design

The website is designed for:

* Desktop
* Tablet
* Mobile devices

Responsive principles:

* Flexible layouts
* Mobile navigation
* Adjustable spacing
* Optimized content display

---

# Code Organization

Project files are separated by responsibility:

```
css/
├── components/
├── responsive.css
└── style.css

JS/
├── main.js
├── contact.js
└── script.js

Assets/
└── images/
```

This structure improves:

* Maintainability
* Scalability
* Future updates
